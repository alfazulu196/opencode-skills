# Двойное зеркало GitHub+GitLab и бэкапы

## Схема пуша в два облака

Проверенная конфигурация: у `origin` **два pushurl** — один `git push`
уходит в оба облака сразу:

```sh
git remote set-url --push --add origin https://github.com/<user>/<repo>.git
git remote set-url --push --add origin https://gitlab.example:4443/<user>/<repo>.git
```

Второй вариант (равнозначный): отдельные `origin` (github) и `lab`
(gitlab) remote'ы — тогда `git push origin main && git push lab main`.
Важно: после merge внешней заглушки GitLab в main пушится напрямую в
оба (force не нужен, если история не переписывалась).

## Бэкапы репо

Перед любым рискованным действием (пересборка истории, массовые правки)
и по итогам каждого релизного пакета:

```sh
git bundle create backup/repo-YYYYMMDD.bundle --all
```

Бандл — полноценная копия репо одним файлом: восстанавливается клоном
(`git clone repo.bundle repo`). Хранить несколько штук с датой в имени.

## Защищённая main (GitLab)

- force-push в защищённую main запрещён — не пытаться «починить»
  переписыванием истории; исправления — только новыми коммитами.
- Внешние правки через web-редактор GitLab входят merge-коммитом в main;
  после этого обычный `git push` работает без force.

## Кириллица и Windows-консоль

- **PowerShell портит кириллицу** в аргументах команд. Commit-сообщения:
  писать во файл и `git commit -F $env:TEMP\opencode\commit_msg.txt`.
- `.bat`-файлы — только ASCII. Python-скрипты — с `-X utf8`.
- Credentials в Windows Credential Manager; **никогда не печатать** их
  в выводе/логах. Пароль от веб-интерфейса GitLab ≠ API-токен: API-вызовы
  с паролем дают 401 — для API нужен отдельный токен через веб-интерфейс.
- Публичный репозиторий может содержать чувствительные данные из
  тестовых материалов (реальные S/N, MAC, IP) — помнить при выборе
  public/private и не дублировать туда секреты.

## Именование и порядок

- Релизные коммиты: `v1.6.7: фича А, фича Б, ...` (краткий список пакета).
- Проверка после пуша: `git log --oneline -3` локально и в веб-интерфейсах
  обоих облаков — коммит на верхушке в обоих.
