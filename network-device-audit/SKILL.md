# Аудит сетевых устройств с Windows-машины

Паттерны полевых сканеров/аудиторов (коммутаторы MikroTik/Eltex/Qtech,
камеры, Windows-клиенты). Портабельная техника — без привязки к
вендору; конкретные команды лечения — только по назначению.

## Протоколы на чистом питоне (без тяжёлых зависимостей в exe)

- **SNMP v2c без pysnmp**: свой BER-кодек (`_ber_len`, `_enc_oid`,
  `_dec_tlv`, ...) — меньше вес бандла. Один UDP-сокет на серию
  GET/GETNEXT к агенту (context-manager сессия). Отказы
  дифференцировать: «ICMP: порт закрыт — служба выключена», «нет
  ответа за N с», «битый пакет», «агент ответил ошибкой» — инженеру
  нужна причина, а не «таймаут». Исключения агента
  (`noSuchObject`/`endOfMibView`) — не падение; walk строго внутри
  base_oid.
- **FDB**: Q-BRIDGE (1.3.6.1.2.1.17.7.1.2.2.1.2) первым, классический
  BRIDGE (1.3.6.1.2.1.17.4.3.1.*) — фолбэком; скорость порта —
  ifHighSpeed с фолбэком на ifSpeed. Набор MIB-II (sysDescr/sysName/
  ifTable/ARP) стандартен для любого вендора.
- **MNDP (MikroTik)**: UDP/5678 broadcast, TLV через
  `struct.unpack("!HH")`, зонд отправить 3 раза, приём — фоновый поток
  с `stop_event` и таймаутом сокета 0.5 с. Пассивная идентификация
  «MikroTik (model) [MNDP]» без единого credential.
- **Rogue DHCP/DNS без scapy**: RAW-пакет DHCPDISCOVER по RFC 2131 +
  ручной поиск TLV-опций в хвосте BOOTP; DNS-проба — A-запрос
  уникального несуществующего домена всем узлам /24. Грабля: порт 68
  занят службой DHCP Windows — запуск от администратора. Эталон
  легальных DHCP/DNS брать из конфига ОС активного адаптера.
- **Фингерпринт без соединений**: локальный IP — UDP-connect к
  8.8.8.8:80 (трафика наружу нет); рандомизированные MAC смартфонов —
  U/L-бит первого октета (`first_byte & 0x02`); Windows — по
  SSH-баннеру «for_windows»; вендоры камер — по HTTP-заголовку
  `Server` (DNVRS-Webs=Dahua, ACCC-HTTPD=Axis, Reolink-Webs); TCP-
  подсказки (8291 Winbox, 5985 WinRM, 5555 ADB) — `connect_ex` с
  таймаутом 0.2 c (не бросает исключений).
- Ping/ARP кроссплатформенно: `-n`(Win)/`-c`, `-a`/`-n`; время пинга —
  двуязычный regex `(?:Время|Time)\s*[=<]\s*(\d+)` — работает на
  русской и английской локалях. Таймауты 0.2–0.25 c на Wi-Fi слишком
  агрессивны (пробитие джиттера) — 0.5 с и выше.

## WinRM / Windows-клиенты

- Сессия `winrm.Session(f"http://{ip}:5985/wsman", auth=(u,p),
  transport='ntlm')`; вне домена локальному админу нужен
  `LocalAccountTokenFilterPolicy`.
- Русская локаль консоли: вывод `net accounts` декодировать **cp866**
  (не utf-8); парсинг — двуязычными regex
  («Минимальная длина пароля|Minimum password length»).
- Счётчики вместо JSON-парсинга:
  `(Get-NetFirewallProfile | Where-Object {$_.Enabled -eq 'False'}).Count`
  — фикс ложных пропусков.
- Правило «команда → немедленная верификация»:
  `Set-MpPreference`/`Set-NetFirewallProfile`/`net accounts` могут
  молча не сработать (Tamper Protection) — перечитывать результат,
  иначе «[КРИТИЧНО] не активировалось — проверьте вручную!».
- Фолбэк, когда WinRM закрыт: пассивный аудит открытых служб
  (SMB 445 → угроза WannaCry).

## Парсинг конфигов коммутаторов

- Ошибки доступности и авторизации — РАЗНЫЕ категории (закрытый порт
  ≠ неверный пароль); недоступен SSH → пассивный комплаенс по
  открытым портам.
- MikroTik: `/ip service print without-sharing` (utf-8/ignore), LLDP из
  `/ip neighbor print detail` — двойной парсер (kv «key="value"» +
  фолбэк колоночный); SSH-порт бывает 22 ИЛИ 2222 — пробовать оба.
- Eltex MES (netmiko, `device_type='eltex'`): маркеры аудита в
  running-config; лечение «line ssh → port 2222 → write memory» +
  пост-проверка по running-config.
- Мусор reverse-DNS («(DESKTOP-ALFA, HOME, 2)») чистить regex
  `[\[\]()'\\",\s]`.

## Брутфорс и камеры — гигиена

- Axis/свежие Hikvision **блокируют IP клиента** за серию неверных
  паролей — не заливать большие словари; Reolink по умолчанию держит
  RTSP выключенным в веб-настройках.
- paramiko «Error reading SSH protocol banner» — типовой отказ (порт
  открыт, но это не SSH или устройство режет баннеры): переживать
  исключение, не ронять поток; `banner_timeout=1.0`.
- RTSP-пути вендоров — во внешнем JSON (rtsp_config.json), дополняется
  без пересборки exe; OpenCV-грабли — см. скилл `pyinstaller-windows`.
- Деградация: «OpenCV нет → пропустить брутфорс RTSP (только
  веб-панели)» — не падение.

## Hardening-словарь и проверка эффекта

- Структура словаря «порт → (серьёзность, описание, как проверить
  вручную, fix × N платформ, откат)» переносима целиком;
  firewall-генератор выдаёт готовые ACL для 3 платформ с блоком
  отката (для Cisco помнить: порядок строк ACL критичен).
- Эффект лечения проверять снимками состояния До/После: `state_*.json`
  + фиксированный словарь событий диффа («НОВЫЙ ХОСТ», «ОТКРЫЛСЯ ПОРТ
  — лечение сработало», «НОВЫЙ БОЕВОЙ CVE»). Мониторинг по sysUpTime с
  детектом перезагрузки.
- Внешние фиды (CVE/KEV) — трёхуровневый фолбэк «свежий кэш → сеть →
  устаревший кэш», исключений не бросает.
- Headless-конвейер и контракт ошибок — см. скилл
  `pyqt-desktop-gotchas`.
